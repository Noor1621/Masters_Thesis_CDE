# Hohe Tauern Snow Thesis Website

Thesis website — Integration of SAR and Optical Satellite Data for Delineation of Dry and Wet Snow Cover in the Hohe Tauern National Park, Austria

**Integration of SAR and Optical Satellite Data for Delineation of Wet and Dry Snow in Hohe Tauern National Park, Austria**

The website presents the study background, objectives, methodology, results, climatic drivers, discussion, conclusion, references, Google Earth Engine code, and a multi-year snow variability comparison using the original supplied composite JPEG maps.

## Live website

After enabling GitHub Pages, the site will be available at:

`https://YOUR-GITHUB-USERNAME.github.io/hohe-tauern-snow-thesis/`

Replace `YOUR-GITHUB-USERNAME` with your GitHub username. If you choose a different repository name, replace `hohe-tauern-snow-thesis` as well.

## Publishing with GitHub Pages

1. Create a public GitHub repository.
2. Upload all files and folders from this project to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main**, folder **/(root)**, and save.

## Structure

- `index.html` — home page
- `css/` — styles and local fonts
- `pics/` — figures, maps, logos, and images
- `docs/` — thesis and poster PDFs
- Other `.html` files — thesis chapters and tools
